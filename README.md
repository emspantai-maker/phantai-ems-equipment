# ระบบตรวจสอบอุปกรณ์ประจำรถพยาบาล
## หน่วยกู้ชีพเทศบาลเมืองพันท้ายนรสิงห์ (Phantai EMS Equipment Check)

Web Application แบบ Progressive Web App (PWA) ระดับมืออาชีพ สำหรับการตรวจสอบอุปกรณ์ประจำรถพยาบาลฉุกเฉิน 3 คัน (`กข9745`, `กค7080`, `กง3002`) รองรับเวรเช้า (08:00–20:00) และเวรดึก (20:00–08:00) ครบ 40 รายการ พร้อมระบบความปลอดภัยและการตรวจสอบตามเกณฑ์ EMS สากล

## 1. ภาพรวมของระบบและหลักการทำงาน

ยึดหลักสำคัญ: **“ไม่มีการตรวจ = ไม่มีการผ่าน”**
- อุปกรณ์ทั้ง 40 รายการเริ่มต้นเป็น **🔴 ยังไม่ได้ตรวจ (`NOT_CHECKED`)** เสมอ
- **น้ำกลั่น (รายการที่ 5)**: บังคับตรวจด้วยตนเองทุกวัน (จันทร์-อาทิตย์) และ **ปุ่ม Auto Ready จะไม่เปลี่ยนสถานะน้ำกลั่นเด็ดขาด**
- **น้ำมันเชื้อเพลิง (รายการที่ 6)**: ไม่ต่ำกว่า 1/2 ถัง
- **ออกซิเจน No.1, No.2, No.3 (รายการที่ 36-38)**: เกณฑ์ไม่ต่ำกว่า 500 psi กรอกตัวเลขจริง
- **รายการจำนวนขั้นต่ำ**: ตรวจนับจำนวนจริง เช่น Hard Collar=3, ไม้ดาม=4, หน้ากาก=3, DTX=1
- **ระบบ Batch Operations**: บันทึกข้อมูลทั้ง 40 รายการในคำสั่งเดียว ป้องกันข้อมูลสูญหายและป้องกัน Double Submit

## 5. วิธีตั้งค่า Environment Variables (.env)

สร้างไฟล์ `.env` ในโฟลเดอร์หลักของโปรเจกต์:

```bash
VITE_SUPABASE_URL=https://your-project-id.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key-here
VITE_APP_NAME="ระบบตรวจสอบอุปกรณ์ประจำรถพยาบาล"
VITE_ORG_NAME="หน่วยกู้ชีพเทศบาลเมืองพันท้ายนรสิงห์"
VITE_DEFAULT_TIMEZONE="Asia/Bangkok"
```

> **ข้อควรระวัง**: ห้ามนำ Service Role Key มาใส่ใน Frontend ให้ใช้เฉพาะ Anon Key เท่านั้น!

## 6. วิธี Run ในเครื่องตัวเอง (Local Development)

1. เปิด Terminal ในโฟลเดอร์โปรเจกต์ `phantai-ems-equipment`
2. ติดตั้ง Dependencies:
   ```bash
   npm install
   ```
3. รันเซิร์ฟเวอร์สำหรับพัฒนา:
   ```bash
   npm run dev
   ```
4. เปิดเบราว์เซอร์ไปที่ `http://localhost:3000`

## 8. วิธี Deploy ขึ้น GitHub Pages

1. ใน `vite.config.js` เพิ่ม `base: '/<ชื่อ-repo>/'`
2. Push Source Code ขึ้น GitHub
3. ไปที่ GitHub Repository Settings -> **Pages**
4. ในส่วน Build and deployment เลือก **GitHub Actions** -> เลือก **Static HTML / Vite**
5. เมื่อ Workflow ทำงานเสร็จสิ้น จะได้ URL พร้อมใช้งาน เช่น `https://username.github.io/phantai-ems-equipment/`

---

## 9. วิธี Deploy ขึ้น Cloudflare Pages

1. เข้าหน้า [Cloudflare Dashboard](https://dash.cloudflare.com/) -> **Workers & Pages** -> **Create application** -> **Pages**
2. เชื่อมต่อ GitHub Repository
3. ตั้งค่า Build Settings:
   - **Framework preset**: `Vite`
   - **Build command**: `npm run build`
   - **Build output directory**: `dist`
4. ในส่วน **Environment Variables** เพิ่ม `VITE_SUPABASE_URL` และ `VITE_SUPABASE_ANON_KEY`
5. กด **Save and Deploy** จะได้รับโดเมน `.pages.dev` ทันที

## 10. วิธีติดตั้ง Web App ลงบนมือถือ (PWA Installation)

### บน Android (Google Chrome):
1. เข้า URL ของระบบ
2. กดจุดสามจุด (⋮) ด้านขวาบน
3. เลือก **“เพิ่มลงในหน้าจอหลัก” (Add to Home Screen)** หรือกดปุ่มแจ้งเตือน **“ติดตั้งแอป”**

### บน iOS (Safari):
1. เข้า URL ของระบบผ่าน Safari
2. กดปุ่ม **แชร์ (Share Icon - รูปสี่เหลี่ยมลูกศรชี้ขึ้น)**
3. เลื่อนลงมาเลือก **“เพิ่มไปยังหน้าจอโฮม” (Add to Home Screen)**
4. กด “เพิ่ม” (Add)

## 12. การเพิ่มสมาชิกและการอนุมัติผู้ใช้งาน

1. ผู้ใช้งานใหม่เข้าหน้า **สมัครสมาชิก** กรอก Username, ชื่อ-นามสกุล, รหัสพนักงาน, ตำแหน่ง, รหัสผ่าน
2. หลังสมัคร สถานะจะเป็น **รอการอนุมัติ (`approved: false`)**
3. Admin เข้าสู่ระบบ -> เมนู **Admin Console** -> แท็บ **อนุมัติ & สมาชิก**
4. Admin กดปุ่ม **[อนุมัติ]** เพื่อเปิดสิทธิ์ หรือกด **[ระงับ/ปฏิเสธ]** ได้ทันที

## 13. การเพิ่มและจัดการรถพยาบาลคันใหม่

1. Admin เข้าเมนู **Admin Console** -> แท็บ **จัดการรถพยาบาล**
2. กดปุ่ม **+ เพิ่มรถพยาบาลคันใหม่**
3. กรอกรหัสรถ, ป้ายทะเบียน, ชื่อเรียก และประเภทรถ
4. เมื่อกดบันทึก รถคันใหม่จะปรากฏในระบบตรวจสอบทันทีโดยไม่ต้องแก้ไข Code
